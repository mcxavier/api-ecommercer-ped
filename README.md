# api-ecommercer-ped
Api de gestão de pedidos de um e-commerce estrutura em arquitetura CRQS e Clean Architecture.

O codigo esta organizado nas camadas: Core, Infraestructure, e Presentation.

Na cama de Core, estão agrupados os codigos de Domain e Application;
Já na camada Infraestructure, estão os codigos da camada de persistencia
E por fim, na camada de Presentation, está a Web Api propriamente dita.

Na web api, utilizei o Swagger pra documentação, e escolhi a estrutura de Controllers ao invés das minimals apis, e a raão pra isso é que acho que o projeto fica mais estruturado e organizado
